This project included implementing code for computing the mechanics of soft filaments using the Cosserat Rod Theory (CRT). I constructed a model of a soft swimming flagella and deployed Covariance Matrix Adaptation Evolution Strategy (CMA-ES) to optimize the flagella for maximum for its maximum forward velocity. Nodal masses and elemental frames were discretized withnumerical discretization. The energy-preserving second-order position-Verlet scheme was utilized.
